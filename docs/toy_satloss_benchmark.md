# Analytic 3D Sampling-Robustness Benchmark

## Purpose

This benchmark isolates the claim tested by SATLOSS: a neural operator can
produce different fields when its *input point-sampling density* changes,
despite the underlying geometry and requested output locations remaining
unchanged.  It is self-generated, deterministic, and is an exact manufactured
isotropic Poisson PDE with analytic solution and normal-flux targets; there is
no external mesh generator, CFD/FEA solver, or label noise.

## Geometry And Fields

Every case is a rotated, anisotropic, smooth star-shaped solid with bounded
low-order angular deformation and one local bump.  It defines an exact
geometry-parameterized isotropic Poisson PDE: the volume target is its analytic
solution and the surface target is its outward physical normal flux.  The case
parameters are stored in each `case_metadata.json`, making every sample fully
reproducible from its seed.

## Critical Distribution Separation

`geometry_coords.npy` is an encoder-only cloud generated by a case-specific
nonuniform virtual-meshing density.  It intentionally contains smooth global
and localized density variation.  `surface_coords.npy` and `volume_coords.npy`
are independent reference query clouds and carry the analytic targets.
All models, all shift magnitudes, and both methods use exactly the same query
points and targets.  Thus the comparison changes only encoder sampling.

## Training Protocol

`toy_satloss.yaml` trains the SMART baseline with an epoch-seeded uniform 16K
subset of the native 131K encoder cloud.  `toy_satloss7.yaml` retains the full
131K source and draws two 16K views.  Each SATLOSS view uses the same random
shift family for the batch: inverse-KDE beta reweighting, sine-x mixture, or
sine-y mixture.  The objective is fixed and directly interpretable:

`0.2 * L_supervised(view1) + 0.2 * L_supervised(view2) + 0.6 * L_prediction_match(view1, view2)`.

There is no learned task weighting, soft worst-case selection, or warm-up in
this benchmark.

## Evaluation Protocol

The evaluation script computes surface and volume relative L2 errors after
denormalization, then reports their equal-weight mean as global relative L2.
It evaluates beta, sine-x, and sine-y at matched endpoint grids.  The endpoint
bar plots annotate only SATLOSS bars with the percentage error change relative
to SMART Base.  Per-case values are written as tidy CSV, so confidence
intervals, paired tests, and alternative aggregations can be added without
rerunning inference.

## Reproducibility

The generator uses a fixed master seed and deterministic case IDs.  The train
and validation IDs are recorded in `preprocessed_manifest.json`; normalization
uses only training cases.  KDE-16 log-density caches are generated after the
global training bounds are known, so their indexing exactly matches
`geometry_coords.npy` and the SATLOSS sampler.

`visualize_toy_satloss_examples.py` reconstructs the exact parametric surface
from the stored parameters.  It exports a triangular surface VTP with both the
analytic surface field and native encoder-density field, a valid volume-point
VTP with the analytic volume field, and a high-resolution PNG overview.

## Remeshing Evaluation

`export_toy_satloss_surface_vtps.py` reconstructs triangular analytic surfaces
for validation cases.  The general VTP decimator then produces angle-preserving,
isotropic, and voxel/quadric sources at approximately 5x and 10x reductions.
The toy comparator samples encoder points directly from those VTP vertices and
does not apply an additional beta or sine shift to a remeshed source.  Surface
and volume query clouds remain fixed, so these are pure encoder-distribution
tests.
